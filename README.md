# ModusOper — téléchargements pour Windows

ModusOper est une application de gestion de budget pour Windows. Vos comptes,
transactions et budgets sont conservés localement sur votre ordinateur.

Ce dépôt est le point de distribution officiel des versions Windows de ModusOper.

**La première version publique est en préparation. Aucun installateur n'est
actuellement disponible.**

Les versions publiées seront disponibles dans la rubrique
[Releases](https://github.com/MLP-Sola/modusoper-download/releases), avec les notes
de version, les fichiers à télécharger et leurs empreintes SHA-256.

Pour installer ModusOper, utilisez le fichier Windows joint à une version publiée.
Les archives « Source code » générées automatiquement par GitHub ne contiennent
pas l'application à installer.

Présentation du logiciel et informations : [modusoper.fr](https://modusoper.fr/).
